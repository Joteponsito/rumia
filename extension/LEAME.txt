RUMIA PARA CHROME - Dos Banderas
================================
Instalar (una sola vez):
1. Descomprima esta carpeta en un lugar fijo (no la borre después).
2. En Chrome abra: chrome://extensions
3. Active "Modo de desarrollador" (arriba a la derecha).
4. Toque "Cargar extensión sin empaquetar" y elija esta carpeta.
5. Fije la extensión: ícono de rompecabezas > alfiler junto a "Rumia".

Usar:
1. Entre a su monitoreo web (Fulinks, HerdsMate u otro) con su usuario.
2. Abra la lista que quiera: celos, salud, producción...
3. Toque el ícono de Rumia > "Leer las tablas de esta página".
4. Toque "Abrir Rumia". Si la lista tiene varias páginas, lea cada una: las filas se juntan.

Los datos se quedan en este navegador. No se suben a ningún servidor.
